# Mashhad Monitor Bot — V1

هذه نسخة تأسيسية أولى للنظام.

## الوظائف الموجودة

- Telegram bot على python-telegram-bot 21.6
- Web health server مناسب لـ Render
- SQLite لتخزين المصادر والمواد
- إضافة/عرض/حذف المصادر
- منع تكرار المواد بواسطة fingerprint
- فحص دوري للمصادر
- عزل أخطاء مصدر عن بقية المصادر
- نشر المواد المصنفة مبدئياً كـ "مهمة" في القناة
- تقرير يومي الساعة 00:00 بتوقيت Asia/Aden
- لوحة بداية بسيطة

## Environment Variables

راجع `.env.example`.

## Render

استخدم Start Command:

```text
python bot.py
```

يجب تشغيل **نسخة واحدة فقط** من هذا البوت باستخدام نفس BOT_TOKEN عند استعمال polling.

## ملاحظة مهمة

هذه V1 تأسيسية. خوارزمية "أهمية الخبر" والصياغة التحريرية الحالية أولية وليست نظاماً تحريرياً نهائياً. المرحلة التالية يجب أن تضيف طبقة أقوى لاستخراج المواد من كل نوع من المصادر، ثم طبقة تحرير/تلخيص، ثم تحسين التقرير اليومي ليكون تقرير رصد تحليلياً منظماً.
