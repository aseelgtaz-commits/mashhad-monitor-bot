# Mashhad Monitor Bot — Daily Current News
- أخبار اليوم فقط: من 00:00 حتى لحظة الطلب بتوقيت Asia/Aden.
- لا يعتمد وقت اكتشاف الرابط كتاريخ نشر.
- يعتمد RSS/Atom أو JSON-LD/meta/time في صفحة الخبر.
- الخبر بلا تاريخ نشر موثوق لا يدخل أخبار اليوم.
- المواد القديمة في قاعدة البيانات السابقة تُعامل كغير موثقة.
- التقرير يُرسل كملف Word عربي قابل للتعديل ومنسق.
- ضع BOT_TOKEN الحقيقي في Render فقط، ولا تضعه في GitHub.
- Start Command: `python bot.py`
